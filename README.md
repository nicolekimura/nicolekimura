## Projeto em destaque

### YouTube Resumidor

Projeto pessoal em desenvolvimento que recebe a URL de um vídeo, extrai sua transcrição, gera um resumo em português com a API do Gemini e salva o resultado em SQLite.

| Etapa | O que acontece |
| :--- | :--- |
| Extração | Obtém a transcrição com `youtube-transcript-api`. |
| Transformação | Gera o resumo com a API do Gemini. |
| Armazenamento | Salva URL, resumo e data de geração em SQLite. |

**Tecnologias:** Python, SQLite, `google-genai`, `youtube-transcript-api` e `python-dotenv`.
